# QuickCopy

자주 쓰는 문구(주소, 계좌번호, 이메일 서명, 인사말 템플릿 등)를 저장해 두고
필요할 때 **한 번의 탭/클릭으로 클립보드에 복사**하는 앱입니다.

서버가 없고, 모든 데이터는 **이 기기의 브라우저 안에만** 저장됩니다.
어떤 데이터도 외부로 전송되지 않습니다.

---

## 1. 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + JS 인라인) — 이 파일만 열어도 동작 |
| `manifest.webmanifest` | PWA 매니페스트 (앱 이름·아이콘·표시 모드) |
| `sw.js` | Service Worker (오프라인 캐시) |
| `icon-192.png` | Android 홈 화면 / 작업 표시줄 아이콘 |
| `icon-512.png` | 스플래시 화면 아이콘 |
| `icon-maskable-512.png` | Android adaptive 아이콘 |
| `apple-touch-icon.png` | iOS 홈 화면 아이콘 (180×180) |
| `favicon.svg` | 브라우저 탭 아이콘 (벡터) |
| `README.md` | 이 문서 |

외부 라이브러리·웹폰트·CDN을 **하나도 사용하지 않습니다.** 그래서 네트워크가 완전히
끊긴 상태에서도 100% 동작합니다.

---

## 2. 사용법

### 기본 조작

| 조작 | 결과 |
|---|---|
| 문구 본문 탭/클릭 | 클립보드에 복사 |
| 오른쪽 아래 **＋** | 문구 추가 (목록 최상단에 들어갑니다) |
| `⠿` 끌기 | 순서 변경 (마우스·터치 모두 지원) |
| `▲` `▼` | 한 칸 위/아래로 이동 |
| `✎` | 문구 편집 |
| `🗑` | 삭제 (5초간 **실행 취소** 가능) |
| 헤더 🔍 | 검색 |
| 헤더 ☀/🌙 | 테마 전환 (시스템 → 라이트 → 다크 → 시스템) |
| 헤더 ⋯ | 가나다순 정렬, JSON 내보내기·가져오기, 전체 삭제, 앱 정보 |

### 가나다순 정렬

수동으로 옮기는 대신 **⋯ → 가나다순 정렬** 을 누르면 문구 내용을 기준으로 목록
전체를 한 번에 다시 정렬합니다. **오름차순(ㄱ→ㅎ)** 과 **내림차순(ㅎ→ㄱ)** 중에서
고를 수 있습니다.

- 대소문자를 구분하지 않고, 앞뒤 공백과 줄바꿈은 무시합니다.
- 숫자는 글자가 아니라 크기로 비교합니다(`2번` 이 `10번` 보다 앞).
- 정렬 직후 토스트의 **실행 취소** 를 누르면 이전 순서로 되돌아갑니다.
- 이미 그 순서면 아무것도 바꾸지 않고 "이미 정렬된 상태입니다" 를 알립니다.

> 검색으로 목록이 걸러진 상태에서는 순서 변경이 잠깁니다.
> 보이지 않는 항목 사이로 옮기면 결과를 예측할 수 없기 때문입니다.
> 검색어를 지우면 다시 풀립니다.

### 키보드 단축키 (PC)

| 키 | 동작 |
|---|---|
| `N` | 새 문구 추가 |
| `/` | 검색 |
| `1` ~ `9` | 해당 순번 문구 복사 |
| `Ctrl+Enter` | 입력창에서 저장 |
| `Esc` | 창/검색 닫기 |

## 3. 실행 방법

### 3.1 PC에서 그냥 열기

`index.html` 을 더블클릭하면 됩니다. 별도 서버나 설치가 필요 없습니다.

단, `file://` 로 열면 브라우저 정책상 **설치(PWA)와 오프라인 캐시 기능은 동작하지
않습니다.** 문구 저장·복사·순서 변경 등 앱 기능은 모두 정상 동작합니다.

### 3.2 GitHub Pages 로 배포하기 (권장)

프로젝트 폴더(`..\`)에서 다음을 실행하면 GitHub Pages 저장소에 배포됩니다.

```
python 11_DeployToPages.py
```

- 배포 위치: `D:\Temp\gh\cwheo\Pages-WebApp\docs\QuickCopy`
- 앱 실행 주소: https://cwheo.github.io/Pages-WebApp/QuickCopy/
- 저장소 웹 주소: https://github.com/cwheo/Pages-WebApp/tree/main/docs/QuickCopy

보조 스크립트:

| 파일 | 용도 |
|---|---|
| `09_ChangeVersionName.py` | 버전 일괄 변경 (`index.html`·`sw.js`·매니페스트) |
| `001_Local_Repository_Pages_OpenFolder.bat` | 배포된 로컬 폴더 열기 |
| `001_Remote_Repository_GitHub_Pages.bat` | 저장소 웹 페이지 열기 |

### 3.3 스마트폰에 설치하기 (Netlify Drop 배포)

1. https://app.netlify.com/drop 에 접속합니다.
2. 이 **폴더 자체**를 페이지 위로 드래그 앤 드롭합니다.
   (폴더 안의 파일들을 낱개로 올리지 말고, 폴더를 통째로 올립니다.)
3. 잠시 뒤 `https://<임의이름>.netlify.app` 주소가 만들어집니다.
   원하면 Netlify 사이트 설정에서 이름을 바꿀 수 있습니다.
4. 스마트폰 브라우저로 그 주소에 접속합니다.
   - **Android / Chrome**: 헤더의 **설치** 버튼 또는 메뉴의 "앱 설치"
   - **iPhone / Safari**: 하단 **공유** → **홈 화면에 추가**
5. 홈 화면에 QuickCopy 전용 아이콘이 생기고, 이후에는 **데이터 네트워크 없이도**
   실행됩니다(비행기 모드에서도 동작).

Netlify는 기본으로 HTTPS를 제공하므로 PWA 설치 요건이 자동으로 충족됩니다.
`netlify.toml` 같은 별도 설정 파일은 필요하지 않습니다.

## 4. 데이터 백업 (중요)

문구는 브라우저의 `localStorage` 에 저장됩니다. 따라서 다음 상황에서 **사라질 수
있습니다.**

- 브라우저의 "인터넷 사용 기록/사이트 데이터 삭제" 실행
- 앱(홈 화면 아이콘) 삭제 후 재설치
- 기기 초기화 또는 교체
- 사생활 보호(시크릿) 모드에서 사용

### 백업하는 방법

1. 헤더 **⋯** → **JSON 내보내기**
2. `quickcopy-backup-YYYYMMDD-HHMM.json` 파일이 다운로드됩니다.
3. 이 파일을 클라우드 드라이브나 메일에 보관하세요.

### 복원 / 다른 기기로 옮기는 방법

1. 새 기기에서 앱을 열고 헤더 **⋯** → **JSON 가져오기**
2. 백업 파일을 선택합니다.
3. **덮어쓰기** 또는 **기존 뒤에 추가** 중에서 고릅니다.
4. 잘못 가져왔으면 화면 아래 토스트의 **실행 취소** 를 누르면 되돌아갑니다.

> 기기 간 자동 동기화 기능은 없습니다(서버가 없기 때문입니다).
> JSON 파일이 곧 이동 수단입니다.

## 5. 자주 있는 질문

**Q. 복사가 안 됩니다.**
브라우저가 클립보드 접근을 막은 경우입니다. 앱은 자동으로 예비 수단을 시도하고,
그마저 막히면 "수동으로 복사해 주세요" 창을 띄워 내용을 선택된 상태로 보여줍니다.
`Ctrl+C` 로 복사하면 됩니다. HTTPS(Netlify 주소)로 접속하면 대부분 해결됩니다.

**Q. 문구를 수정했는데 앱에서 옛 화면이 보입니다.**
Service Worker 캐시 때문입니다. 버전을 올린 뒤 다시 배포하세요.
프로젝트 폴더의 `09_ChangeVersionName.py` 의 `NEW_VERSION` 을 고쳐 실행하면
`index.html` 의 `APP_VERSION` 과 `sw.js` 의 `CACHE_NAME = 'quickcopy-v<버전>'` 이
함께 바뀝니다. 새 버전이 감지되면 앱이 "새 버전이 준비되었습니다 [새로고침]"
안내를 띄웁니다.

**Q. 저장 공간이 가득 찼다고 나옵니다.**
`localStorage` 한도(약 5MB)에 도달한 경우입니다. JSON으로 내보내 백업한 뒤
필요 없는 문구를 지우세요.

**Q. 아이콘을 바꾸고 싶습니다.**
`favicon.svg` 를 수정한 뒤, 프로젝트의 `tools\make_icons.py` 를 같은 기하로
맞춰 고치고 `python make_icons.py` 를 실행하면 PNG 4종이 다시 만들어집니다.
(Python + Pillow 필요)
